# Post-R1 opportunity ledger

`accepted_exact.csv` contains exact isolated roundtrip results only.

`candidate_edges.csv` ranks donor/source pairs. Expected and high values are calibrated screening estimates, never submission claims.

`recipient_priority.csv` gives one next trial per canonical page-aligned group. SCR2 columns are exact raw macro opportunity mapped from the round-trip-verified SCR2 stream, but its entropy estimate remains zero until a cost-positive virtual-replay oracle confirms a win.

`mini11_oracle_high` is a C421 class-prior upper bound. Its expected net is deliberately zero because the current 11-model oracle does not pay for selection plus executable cost.

All proposed modes are recipient scoped. Donor bytes and virtual replay must update only their specialist/event coder; original bytes continue through PPMd, LSTM, FXCM, match models, and the main mixer unchanged.
